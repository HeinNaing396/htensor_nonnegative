# htensor_nonnegative

This repository contains code for a **multiplicative update algorithm** to compute the **nonnegative hierarchical Tucker decomposition** (NHTD). Examples demonstrating the application of the code to data are available in the ITPC and chicago_crime folders. The following MATLAB toolboxes were used:

- **EEGLAB**, Version 2026.0.0
- **Hierarchical Tucker Toolbox**, Version 1.3
- **Tensor Toolbox for MATLAB**, Version 3.8

The following datasets are used in the examples:

- **New Chicago Crime Tensor Dataset (Version 3.0)**  
  T. G. Kolda, November 2024  
  https://gitlab.com/tensors/tensor_data_chicago_crime

- **Tutorial Dataset 2**  
  M. Mørup, 2006  
  https://www.erpwavelab.org/index_files/Page361.htm

This repository was not designed for hierarchical Tucker decompositions with a non-binary tree.
